DRM/KMS Adreno DPU driver architecture
----------------------------------------

To access the display hardware block, use the DRM/KMS Linux kernel framework and related drivers.

The DRM/KMS driver framework and the driver implementation information are
available to licensed developers with authorized access. For more information, see
`Qualcomm Linux Display Guide -
Addendum <https://docs.qualcomm.com/bundle/resource/topics/80-70030-18A/architecture.html>`__.
